# История изменений

## 2.0.0 — 2026-10-09

Полная переработка.

### Интерфейс
- Новый дизайн: тёмная тема, крупные заголовки шагов, белый блок документа, шрифты Unbounded / Manrope / JetBrains Mono (локально, с кириллицей).
- Один сквозной сценарий: 01 Шаблон → 02 Запись → 03 Поля → 04 Документ → Журнал.
- Адаптивная вёрстка для планшета и телефона, поддержка клавиатуры, уменьшенная анимация по системной настройке.

### Функции
- Правка полей перед сборкой с указанием источника значения.
- Автоматическое обращение и окончание («ый»/«ая») из ФИО по отчеству.
- Пакетная сборка: отмеченные записи × выбранные шаблоны → один ZIP.
- Загрузка своего шаблона `.docx` и собственного файла данных `.xlsx`/`.csv` без изменения репозитория.
- Журнал сборок с повтором и выгрузкой в CSV.
- Печать или сохранение в PDF только листа письма.
- Поиск: исключение `-слово`, условия `столбец:значение`, автоматический выбор единственного совпадения.
- Служебные теги `[[Дата]]`, `[[Строка]]`, `[[Шаблон]]`; шаблон имени файла с подстановками.
- Настройки в браузере, `config.js`, параметры адресной строки (`?sheet`, `?template`, `?row`, `?q`).
- Предпросмотр с бланком организации.

### Надёжность
- Список шаблонов из `templates/manifest.json` (без лимитов GitHub API), GitHub API — как запасной вариант.
- Шаблон скачивается один раз и кэшируется в памяти; теги читаются по абзацам, поэтому разбитые Word'ом теги распознаются.
- Пустые теги подставляются пустой строкой, а не словом `undefined`; ошибки шаблона показываются с названием тега.
- Библиотеки и шрифты в репозитории (`vendor/`, `fonts/`), CDN — только как запасной вариант.
- Обновлены библиотеки: xlsx 0.18.5, pizzip 3.1.7, docxtemplater 3.47.4, mammoth 1.8.0.

## 1.x

Исходная версия: один `index.html`, список шаблонов через GitHub API, данные из Google Таблицы, предпросмотр и скачивание `.docx`.
