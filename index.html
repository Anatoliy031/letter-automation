Доступ к таблице: «Все, у кого есть ссылка — Читатель». Берётся первый лист, если не указан gid.

Шаблоны

Сначала читается templates/manifest.json рядом с приложением, затем — GitHub API указанного репозитория.

Файлы

Подстановки: {Шаблон}, {Строка}, {Дата} и любой столбец или тег, например {Номер_ТУ}.
