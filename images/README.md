# Изображения

- `letterhead.png` — бланк организации, показывается в предпросмотре над текстом письма (в самих `.docx` бланк уже есть в колонтитуле). Путь задаётся параметром `letterhead` в `config.js`.
- `favicon.svg` — значок вкладки.
- `screenshot.png`, `screenshot-document.png` — снимки интерфейса для README.
