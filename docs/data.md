# Реестр данных

Источник записей — таблица, где первая строка содержит заголовки столбцов, а каждая следующая строка — одно письмо (одного адресата, один объект).

## Google Таблица

1. Откройте таблицу → «Настройки доступа» → «Все, у кого есть ссылка» → роль «Читатель».
2. Скопируйте ссылку и вставьте её в «Настройки» приложения (или ID из ссылки в `config.js`). ID — это часть адреса между `/d/` и `/edit`.
3. Если нужный лист не первый, укажите `gid` — число после `#gid=` в адресе листа.

Приложение запрашивает экспорт в CSV: `https://docs.google.com/spreadsheets/d/<ID>/export?format=csv&gid=<gid>`. Если вместо таблицы приходит страница входа, значит доступ по ссылке не открыт.

Кнопка «Обновить данные» перечитывает таблицу; при открытии страницы она загружается автоматически.

## Файл xlsx / csv

Кнопка «Загрузить файл» читает первый лист книги Excel или CSV целиком в браузере. Файл никуда не отправляется. После перезагрузки страницы снова загружается Google Таблица.

## Столбцы

Имена столбцов свободные — главное, чтобы они совпадали с тегами в шаблонах (см. [templates.md](templates.md)). В поставляемых шаблонах используются:

| Столбец | Пример |
|---|---|
| `Кому_должность` | Директору филиала |
| `Филиал` | Кубаньэнерго |
| `Кому_ФИО` | Иванов Иван Иванович |
| `Обращение` | Иван Иванович — можно оставить пустым, выводится из ФИО |
| `ый_ая` | ый / ая — можно оставить пустым |
| `ОС` | ООО «Оператор связи» |
| `Номер_ТУ` | 12/34 |
| `Место_запрашиваемого_размещения` | г. Краснодар, ул. …, опоры ВЛ-0,4 кВ № 1–40 |

Подпись записи в списке (шаг «Запись») собирается из столбцов, перечисленных в настройке `labelFields` — по умолчанию `Кому_ФИО, Филиал, Номер_ТУ, ОС`. Если ни одного из них нет, показываются первые три столбца.

## Поиск

| Запрос | Что находит |
|---|---|
| `Иванов` | строки, где текст встречается в любом столбце |
| `Филиал=Краснодар` | столбец «Филиал» содержит «Краснодар» (регистр не важен, можно `Филиал:Краснодар`) |
| `"Номер_ТУ=12/34 А"` | условие с пробелом — в кавычках |
| `ОС=МТС Филиал=Сочи` | несколько условий — выполняются все |
| `-ЭСК` | исключить строки, где встречается «ЭСК» |

Если запрос даёт ровно одну строку, она выбирается сама. Поле «Строка» принимает номер строки в таблице (как в Google Таблице: заголовок — 1, первая запись — 2).

## Значения

Все ячейки читаются как текст в том виде, в каком они отображаются в таблице. Числа с ведущими нулями, даты и номера с косой чертой остаются как есть. Пустые столбцы без заголовка получают имена `Столбец_N`; полностью пустые строки пропускаются.
