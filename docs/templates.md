# Шаблоны писем

Шаблон — обычный документ Word (`.docx`). Везде, куда должны подставляться данные, пишется тег в двойных квадратных скобках: `[[Имя_столбца]]`. При сборке тег заменяется значением из выбранной строки реестра.

## Правила

1. **Имя тега = заголовок столбца** в таблице. Пробелы и подчёркивания взаимозаменяемы, регистр не важен: `[[Кому ФИО]]`, `[[Кому_ФИО]]` и `[[кому_фио]]` найдут столбец «Кому_ФИО». Знак `№` в заголовке считается буквой `N`, точки и скобки игнорируются.
2. **Тег набирается целиком, одним куском.** Если внутри скобок менять шрифт, цвет, исправлять опечатку через автозамену — Word разбивает текст на несколько «кусков», и тег может не распознаться. Надёжный способ: набрать тег в Блокноте и вставить в документ, либо выделить весь тег и задать форматирование один раз.
3. Тег можно ставить в любом месте документа: в тексте, таблицах, колонтитулах, сносках.
4. Один тег можно использовать сколько угодно раз.
5. Форматирование тега (жирный, курсив, размер) наследуется подставленным значением.
6. Если значения для тега нет, подставляется пустая строка — документ соберётся без ошибки, а поле будет отмечено в шаге «Поля» и в «Диагностике».
7. Переносы строк в значениях (например, многострочный адрес, введённый в поле вручную) переносятся в документ.

## Служебные теги

Доступны в любом шаблоне, столбца в таблице для них не нужно:

| Тег | Значение |
|---|---|
| `[[Дата]]` | сегодняшняя дата в формате `дд.мм.гггг` (если в таблице есть столбец «Дата», берётся он) |
| `[[Строка]]` | номер строки в таблице (заголовок — строка 1) |
| `[[Шаблон]]` | название шаблона |

## Обращение и окончание

Во всех текущих шаблонах есть фраза `Уважаем[[ый_ая]] [[Обращение]]!`. Если в реестре столбцы «Обращение» и «ый_ая» пустые или отсутствуют, приложение выводит их из столбца «Кому_ФИО» (нужен формат «Фамилия Имя Отчество»):

- отчество на `-вич`, `-ич`, `-оглы` → `ый`, обращение «Имя Отчество»;
- отчество на `-вна`, `-чна`, `-кызы` → `ая`.

Для ФИО с инициалами («Сидоров И.И.») вывести обращение нельзя — заполните его вручную в шаге «Поля» или в таблице. Автоподстановку можно отключить в настройках.

## Проверка нового шаблона

1. Положите файл в `templates/` и выполните `python3 scripts/make_manifest.py` — скрипт перечислит найденные теги. Если какого-то тега нет в списке, он набран с разрывом (см. правило 2).
2. Откройте приложение, выберите шаблон и любую запись. В «Диагностике» видно, какие теги не нашли столбца.
3. Скачайте `.docx` и откройте в Word: все `[[…]]` должны исчезнуть.

## Расширенные возможности docxtemplater

Внутри используется библиотека docxtemplater с разделителями `[[` и `]]`. Поддерживаются условия и циклы:

```
[[#Приложения]]— [[.]][[/Приложения]]
```

Для них данные нужно готовить отдельно, поэтому в текущем реестре они не используются. Подробности: https://docxtemplater.com/docs/tag-types/
