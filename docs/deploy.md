# Размещение

Приложение — статические файлы. Серверная часть не нужна, достаточно любого хостинга, который отдаёт файлы как есть.

## GitHub Pages

1. Загрузите содержимое репозитория в GitHub (ветка `main`, корень репозитория).
2. Settings → Pages → Build and deployment → Source: **Deploy from a branch**, Branch: `main`, папка `/ (root)` → Save.
3. Через одну-две минуты приложение откроется по адресу `https://<пользователь>.github.io/<репозиторий>/`.

Файл `.nojekyll` в корне отключает обработку Jekyll — иначе GitHub Pages пропускает некоторые файлы и папки.

Шаблоны при этом читаются из `templates/manifest.json` того же сайта, GitHub API не нужен. Если репозиторий сделать приватным, Pages остаются доступны только на платных планах.

## Amvera, Gitverse Pages, другой статический хостинг

Загрузите папку целиком (включая `vendor/`, `fonts/`, `templates/`, `images/`). Точка входа — `index.html`. Для входа по паролю используйте средства хостинга или защитную страницу перед приложением — само приложение авторизации не содержит.

## Локально

Откройте `index.html` двойным щелчком — приложение заработает, но из-за ограничений браузера на `file://`:

- список шаблонов будет взят через GitHub API, а не из `manifest.json` (можно вместо этого загрузить `.docx` кнопкой «Свой шаблон»);
- шрифты и библиотеки из папок рядом загрузятся как обычно.

Полноценный вариант — любой локальный сервер, например:

```bash
python3 -m http.server 8080
# затем http://localhost:8080/
```

## Обновление

- **Шаблоны**: положить `.docx` в `templates/`, запустить `python3 scripts/make_manifest.py`, закоммитить.
- **Библиотеки** в `vendor/`: версии указаны в `vendor/LICENSES.md`; при обновлении замените файлы и, при необходимости, адреса CDN-копий в `index.html`.
- **Настройки по умолчанию**: `config.js`.

## Что проверить после размещения

1. Открывается главная страница, в правом верхнем углу — число записей.
2. Карточки шаблонов видны (если нет — проверьте `templates/manifest.json` и доступность файлов `.docx`).
3. Выбор шаблона и записи даёт предпросмотр, «Скачать .docx» отдаёт файл, который открывается в Word без `[[…]]`.
